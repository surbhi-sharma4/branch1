# 📈 Sales Prediction using Machine Learning

## 📌 Project Overview

This project predicts product sales based on advertising expenditures on TV, Radio, and Newspaper using Machine Learning.

## 🚀 Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Linear Regression Model
- Decision Tree Regressor
- Random Forest Regressor
- Model Evaluation
- Sales Prediction
- Business Insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## 📂 Dataset

Advertising.csv

## 📊 Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score

## ▶️ How to Run

1. Clone this repository
2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Open the notebook

```
Sales_Prediction.ipynb
```

4. Run all cells.

## 📈 Business Insights

- TV advertising has the highest impact on sales.
- Radio advertising also contributes significantly.
- Newspaper advertising has comparatively less influence.
- Businesses can use the model to forecast sales before launching campaigns.
